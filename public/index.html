IncidentHub API v1.0

hub-user-2026
Endpoints
GET Listar todos los incidentes

Retorna todos los incidentes registrados. Soporta filtros opcionales por prioridad y estado.

Presiona "Enviar petición" para ver la respuesta
GET Obtener incidente por ID

Retorna el detalle de un incidente específico. Responde 404 si no existe.

Presiona "Enviar petición" para ver la respuesta
POST Registrar nuevo incidente

Crea un incidente. El servidor genera automáticamente: id, status (OPEN) y createdAt.

Presiona "Enviar petición" para ver la respuesta
PUT Actualizar incidente

Actualiza los datos de un incidente existente. Preserva id, status y createdAt.

Presiona "Enviar petición" para ver la respuesta
PATCH Cambiar estado

Actualiza el estado de un incidente. Transiciones permitidas: OPEN→IN_PROGRESS, IN_PROGRESS→RESOLVED/OPEN, RESOLVED→OPEN.

Presiona "Enviar petición" para ver la respuesta
DELETE Eliminar incidente

Elimina un incidente permanentemente. ⚠️ Requiere rol ADMIN — selecciónalo arriba para evitar error 403.

Presiona "Eliminar" para ver la respuesta
